Nikos Baxevanis

I work on fuzzing and testing at the Stacks Foundation. I introduced the first fuzzing tools for the Stacks blockchain and focus on consensus-critical code, deep bugs, and systematic vulnerability discovery.

Outside of blockchain, I focus on testing tools. I maintain Hedgehog, which I helped shape from its early days — it powered Echidna, the first smart-contract fuzzer for Ethereum.

Projects

  • 2022 – present
    Built Pandora — property-based, fuzzing, and invariant testing tools for smart contracts on the Stacks blockchain. Later released as Rendezvous, co-authored with Radu Bahmata.
  • 2016 – present
    Key contributor and current maintainer of Hedgehog — a property-based testing library for Haskell, F#, R, and Scala. Originally architected by Jacob Stanley.
  • 2017 – 2021
    Created Doctest — tests interactive F# examples, similar to doctest in Python. Originally built as an internal tool for Hedgehog.
  • 2017 – 2020
    Ported SplitMix — a splittable pseudorandom generator — to Haskell and F# for use in Hedgehog. Based on work by Steele, Lea, and Flood. Passes all dieharder tests.
  • 2016 – 2017
    Created Write you some QuickCheck — a minimal port of QuickCheck v1 to F#.
  • 2011 – 2020
    Built Fare — generates random text matching a regex. Port of dk.brics.automaton and xeger. Used in AutoFixture and serves as an open-source alternative to Microsoft’s Rex library.
  • 2011 – 2019
    Key contributor to AutoFixture — a widely used .NET testing library (3.5k+ GitHub stars). Contributed major features and supporting tools like Fare. Later submitted to the .NET Foundation.
    Tweet from the first AutoFixture symposium with Mark Seemann, Enrico Campidoglio, Mikkel Christensen, and myself.
