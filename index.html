Nikos Baxevanis

I build testing tools that find hard-to-catch bugs before systems go live. At the Stacks Foundation, I developed fuzzers and model-based testing tools that uncovered consensus flaws and denial-of-service conditions before a major network upgrade. I maintain Hedgehog, a property-based testing library that powered Echidna—the first smart-contract fuzzer for Ethereum. I work across Haskell, F#, .NET, Rust, and TypeScript, with a focus on input shrinking, reproducibility, and instrumentation. My experience scaling Web2 systems for acquired companies grounds my approach to reliability and security in blockchain protocol testing.

    Core contributor to AutoFixture, a .NET testing library (3.5k+ stars). Helped shape AutoFixture 3, introduced novel features and tools like Fare. Project later submitted to the .NET Foundation.
